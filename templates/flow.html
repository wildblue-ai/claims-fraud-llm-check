How this POC was built

Three self-verifying Claude Code subagents, dispatched sequentially. Each phase has a numeric pass condition and either retries within a bounded tuning knob (Phases 1–2) or halts and escalates (Phase 3). Reports go to reports/phase-N.md.

What happens when a reviewer uses the demo

The dashboard is static except for the "Analyze" button, which triggers an HTMX call to a Claude-backed endpoint. Responses are cached in memory so the same claim returns instantly on re-click.

Typical latency: 2–4 seconds for the first click on a given claim · near-instant on repeat (cache hit). Failure modes the Phase 3 verification caught: missing API key, broken template rendering, bad response parsing.
